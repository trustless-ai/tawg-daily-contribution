# ERC-8004: Trustless Agents

## Summary

ERC-8004 defines an interoperable trust layer for agents through identity, reputation, and validation registries. It makes agent discovery and trust signals composable without defining one universal scoring model.

## Status

The canonical ERC is Draft. This page was verified against the current canonical page and the Trustless AI implementation sources at the time in `verified_at`.

## Motivation

Agent communication protocols can describe capabilities and carry messages, but they do not by themselves provide portable identity or independently inspectable trust signals across organizations.

## Architecture

The design separates three registries: an ERC-721-based identity handle, a feedback-oriented reputation registry, and a validation request/response registry. Applications choose how to interpret reputation and validation evidence.

## Interfaces

The maintained org implementation exposes separate identity, reputation, and validation interfaces. The canonical specification remains authoritative when an implementation detail differs.

## State machine

Identity records can be registered, transferred, and updated. Reputation is accumulated as feedback records. Validation proceeds from a request committed to off-chain material to one or more validator responses.

## Implementation

The Trustless AI org maintains Solidity interface material for all three registries. Treat it as implementation evidence, not a substitute for the normative ERC.

## Security considerations

Consumers must account for Sybil behavior, untrusted metadata endpoints, malicious or unavailable validators, and the fact that public signals do not prescribe a correct trust-scoring policy.
