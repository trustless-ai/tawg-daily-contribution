# ERC-8281: Observation Commitment Protocol

## Summary

The agent-ercs implementation draft provides a minimal event-based commitment for off-chain observations: record a digest on-chain and verify it later by recomputation.

## Status

The org implementation was verified. No canonical normative source is registered, so the page does not assert an accepted ERC specification.

## Motivation

An observation can remain off-chain while its existence and integrity at a given chain position remain independently checkable.

## Architecture

An observer hashes an artifact, records the digest, and emits an event. A verifier later recomputes the digest and matches the event and chain position.

## Interfaces

The current interface exposes a digest-recording entry point and an event carrying the digest and committer. It deliberately avoids an on-chain artifact store.

## State machine

The flow is append-only: compute, record, and independently verify. Any revocation or temporal-bound extensions are separate profiles, not part of this registered base implementation.

## Implementation

The org source treats the event log as the public ledger and keeps the observation itself private or externally stored.

## Security considerations

A commitment proves neither the truth of an observation nor who interpreted it correctly. Domain separation, canonical serialization, chain selection, and artifact availability remain critical.
