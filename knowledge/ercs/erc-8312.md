# ERC-8312: Bounded Agent Actions

## Summary

The agent-ercs implementation draft defines envelopes and monotonic meters that bound how much authority or budget an agent flow can consume, including aggregate limits across delegation trees.

## Status

Implementation, interface-ID tests, and community discussion were verified. No canonical normative source is registered, so the page describes a working proposal rather than an accepted standard.

## Motivation

A pre-action read cannot safely enforce a cumulative cap across concurrent or delegated actions. A serialized, publicly auditable meter makes consumption order and conservation explicit.

## Architecture

The base envelope binds a principal, capability commitment, cursor, expiry, and lifecycle. Optional profiles expose budget accounting, contestation, and one conserved root cap across a delegation tree.

## Interfaces

The registered source includes bounded-action, budget-substrate, contestable-envelope, and aggregate-budget interfaces with frozen ERC-165 identifiers.

## State machine

An envelope advances through active consumption and terminal or contested states. Each value-drawing surface must advance the cursor; aggregate mode advances one root-keyed spent value across all descendants.

## Implementation

The org implementation distinguishes metering from non-bypassable enforcement. A custody or execution substrate must ensure that value cannot avoid the meter.

## Security considerations

Per-edge counters are unsafe for aggregate delegation because sibling paths can multiply the effective cap. Administrative reset, decrement, or replacement of a conserved meter also breaks the guarantee.

## Testing and examples

The registered test checks interface identifiers. The implementation source also documents recomputable budget vectors, but no separate registered conformance suite is included in this evidence pack.

## Open questions

- Current evidence gap: `normative_spec` is unregistered.
- Cross-chain conservation and substrate non-bypassability remain outside the base meter.
- Community discussion is informative and cannot create normative authority.
