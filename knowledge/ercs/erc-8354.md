# ERC-8354: Confidential Agent Policy Verdicts

## Summary

The agent-ercs implementation draft gates agent actions with zero-knowledge verdicts that prove compliance with a committed policy without revealing the policy on-chain.

## Status

The Trustless AI implementation source was verified. No canonical normative source or registered test source is available in the current registry.

## Motivation

Some agent policies contain private business, safety, or compliance logic. A verifier should be able to prove an action was permitted without publishing that ruleset.

## Architecture

An off-chain policy engine evaluates an action against a secret policy commitment and produces a proof. An on-chain guard binds the verdict to agent identity, policy root, action commitment, executor, expiry, and single-use nullifier.

## Interfaces

The source includes a confidential-verdict guard, a canonical action-commitment preimage, and a policy-domain registry supporting root rotation and revocation.

## State machine

A domain registers or rotates a policy root, a prover creates a time-bounded verdict, the guard verifies it, and a consumer marks the nullifier used so the verdict cannot authorize another action.

## Implementation

The design is prover-agnostic and can compose with a general proof-verifier interface. Public inputs bind the proof to the intended chain, policy domain, agent, action, and executor.

## Security considerations

Replay protection, nullifier uniqueness, expiry, root-rotation grace, immediate revocation, action-domain separation, and verifier-key governance are all part of the trust boundary.

## Testing and examples

No registered test or example source was available in this operation, so proof-system and on-chain conformance are not verified here.
