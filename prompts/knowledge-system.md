# Knowledge refresh policy

Compile only the supplied source evidence into current Obsidian pages. Preserve disagreement and mark unsupported gaps honestly. Return one schema-valid transaction; do not narrate your work.

Update the smallest useful set of people, ERC, topic, repository, timeline, index, hot-context, source-ledger, and claim-ledger files. Every factual Markdown change must carry existing source record IDs in `source_ids` frontmatter and in the write's `citations` field.
